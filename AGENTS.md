# a.l.i.v.e project instructions

Read PRODUCT.md and DESIGN.md before major work. App lives in `alive/`.
Keep React/TypeScript/Vite/Tailwind/Router/GSAP and Go net/http. Strict types, small purposeful modules, cleanup for animations and listeners. No secrets in frontend or committed env files.
Use `.agents/skills/frontend-design/SKILL.md` for major visual components and `.agents/skills/impeccable/SKILL.md` for design context, critique, accessibility audits and polish. Use `.agents/skills/composio/SKILL.md` only for relevant authorized integrations; the public app never requires Composio. Native Windows CLI integrations must follow current platform support; no authentication without explicit authorization.
Preserve the editorial archive identity, punctuation, neutral ground, large imagery and CD collection. No SaaS cards, invented biography, contact URLs or claims about demo media. Respect aspect ratios.
Use the owner's supplied 2025 and 2026 photo collections for photography and release artwork. Do not reintroduce third-party sample photos. Preserve original images and edits; titles and descriptions are mapped in `alive/docs/photo-catalog.json`. Audio remains explicitly labeled as demonstration material until replaced.
Reference roles: https://huyml.co/ intro and photo carousel; https://a24.raviklaassens.com/ disc archive; https://jesperlandberg.com/ transitions. Never copy their media or proprietary source.
Every interaction must work with keyboard and touch. Respect reduced motion, no autoplay, focus restoration, no scroll trapping. Backend remains read-only with validation and safe local media paths.
For reconstruction changes, read `alive/docs/reference-interactions.md` and its paired comparison gallery before changing spatial geometry or motion. Use the bundled official Playwright CLI skill when available. Distinguish measured DOM properties from frame-calibrated Canvas/WebGL estimates. Do not replace the reconstructed reel, disc depth or aperture with a generic flat slider/curtain. Preserve the explicit Horizontal view alternative, dynamic reduced-motion dismissal and fullscreen focus handoff. Reference artwork belongs only in research evidence, never runtime public assets.
Before delivery run frontend typecheck/lint/build/tests and Go test/fmt/vet; inspect desktop/mobile if browser tooling works. Document actual verification and limitations. Consult `alive/docs/` for reference and review evidence.
